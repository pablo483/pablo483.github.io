# Sudarshan GC — Developer Portfolio

Fast, responsive, zero-dependency portfolio website for **Sudarshan GC** (Software Engineer — Java & Spring Boot Backend), built with semantic **HTML5**, **CSS3**, and vanilla **JavaScript**.

## Features

- **Recruiter-First Layout:** Clear backend pitch, categorized technical stack, architecture-focused project cards, professional experience, and instant contact links.
- **Interactive Filtering & Dark/Light Mode:** Filter projects by architecture pattern (`Redis & Scale`, `Kafka`, `Auth & Security`, `Full-Stack`) and switch between dark and light themes.
- **Zero Build Step:** Pure static HTML/CSS/JS — deploys anywhere (`GitHub Pages`, `Vercel`, or `Netlify`) in seconds and is effortless to update.

## Updating Projects Later

Open `index.html`, scroll to `#projects-grid`, copy one `<article class="project-card">...</article>` block, and update the title, 3 bullet points, tech tags, and GitHub URL.
